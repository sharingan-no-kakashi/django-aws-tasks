# Security policy

This repository is a personal prototype and must not be used in production.
There is no production support or security maintenance commitment.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/sharingan-no-kakashi/django-aws-tasks/security/advisories/new).
Do not put credentials, task payloads, or vulnerability details in public issues.
Include the affected revision, a minimal reproduction, the impact, and any
suggested mitigation. Remove secrets and personal data from logs and examples.

If private reporting is unavailable, open a public issue asking for a private
contact method without disclosing the vulnerability itself.
