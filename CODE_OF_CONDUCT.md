# Code of conduct

Everyone participating in this project is expected to help make it a respectful
place to contribute, regardless of experience, identity, background, or ability.
This applies to issues, pull requests, reviews, and other project spaces.

- Discuss the code and evidence. Give specific, constructive feedback.
- Respect different experiences, reasonable disagreement, and requests to stop.
- Do not harass, threaten, discriminate, share private information, or make
  unwanted sexual comments or advances.
- Do not use project spaces for spam or personal attacks.

Maintainers may edit or remove contributions, close discussions, or restrict
participation when needed to enforce these expectations. They should explain
moderation decisions where doing so does not compromise privacy or safety.

Report concerns privately through a contact method on the
[maintainer's profile](https://github.com/sharingan-no-kakashi). Include links and
relevant context, and avoid posting personal or sensitive details publicly.
Maintainers should handle reports discreetly and consider the safety and privacy
of everyone involved. Security vulnerabilities have a separate
[reporting procedure](SECURITY.md).
